# Code of conduct

Chess Advisor follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be welcoming, be respectful, accept constructive criticism graciously,
and focus on what is best for the people who use the project.

Instances of unacceptable behaviour can be reported privately to the maintainer through
[GitHub](https://github.com/YasWish). All reports will be handled confidentially.
